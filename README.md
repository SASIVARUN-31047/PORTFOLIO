# Sasi Varun - Personal Portfolio

A premium, futuristic personal portfolio website for N Sri Sasi Varun, a Computer Science Engineering student and AI-focused developer.

## Features
- 🚀 Modern futuristic AI/developer design
- 📱 Fully responsive across all devices
- 🎨 Dark theme with glassmorphism UI
- ⚡ Fast performance with React + Vite
- ✨ Smooth scrolling and animations
- 🔧 Highly customizable data structure

## Tech Stack
- React.js
- Vite
- HTML5 / CSS3
- Lucide React (Icons)
- Framer Motion (Animations)

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Customization
All portfolio content can be easily updated in `src/data/portfolioData.js`.
Search for `// PLACEHOLDER` in the data file to find links that need to be updated.

## Deployment
This project is frontend-only and can be easily deployed to Vercel, Netlify, or GitHub Pages.

**Vercel / Netlify Deployment:**
1. Connect your GitHub repository.
2. Build command: `npm run build`
3. Publish directory: `dist`
